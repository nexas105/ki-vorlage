# Offene Punkte für den Betrieb

Diese Liste ist die Übergabe an den Entwickler. Alles hier fehlt im Prototyp bewusst.

> Bevor das Tool online geht oder mit echten Daten genutzt wird, muss ein Entwickler
> diese Punkte umsetzen.

## Immer
- [ ] Login / Zugangsschutz
- [ ] Hosting, Domain, HTTPS
- [ ] Backups der Datenbank und Uploads
- [ ] Datenschutz-Prüfung (DSGVO)
- [ ] Eingaben und Uploads absichern

## Projektspezifisch
- [ ] <z. B. Echter Mailversand für Kundenbenachrichtigung (aktuell nur /outbox)>
- [ ] <z. B. Rollen: Büro sieht alles, Fahrer nur eigene Touren (aktuell per Umschalter simuliert)>
