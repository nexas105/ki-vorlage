# Fragerunden

Protokoll aller Planungsrunden zu diesem Projekt. Die KI trägt jede Runde direkt nach den
Antworten ein: Frage, Antwortmöglichkeiten, gewählte Antwort, Datum. Neue Planungen
(z. B. für eine spätere Erweiterung) kommen als neuer Abschnitt **oben** dazu.

So bleibt nachvollziehbar, warum etwas so gebaut wurde. Für Tobias ist das die
Grundlage beim Betriebsfertig-Machen.
